Word Work – a calm, distraction-free word processor for culture journalists
and writers, now as a native app for macOS, Windows and Linux.

**Which file?** Mac with Apple chip → `macOS-AppleSilicon.dmg` · Mac with
Intel → `macOS-Intel.dmg` · Windows → `Windows-x64-setup.exe` · Linux →
`.deb`, `.rpm` or `.AppImage`.

The apps are not yet signed by Apple/Microsoft: the first start needs one
confirmation (macOS: *System Settings → Privacy & Security → Open Anyway*;
Windows: *More info → Run anyway*). Step-by-step instructions and checksum
verification: [docs/INSTALL.md](REPO_URL/blob/main/docs/INSTALL.md). Checksums of
all files are in `SHA256SUMS`.
